# Security Policy / 보안 정책

## Supported Versions / 지원 버전
| Version | Supported |
|---|---|
| Latest version on the Chrome Web Store (1.2.x) | ✅ |
| Older versions | ❌ (please update / 최신 버전으로 업데이트해 주세요) |

## Reporting a Vulnerability / 취약점 신고
Please **do not** open a public issue for security problems.
보안 문제는 공개 이슈에 올리지 말아 주세요.

- Preferred: GitHub **Security → Report a vulnerability** (private)
  권장: GitHub **Security 탭 → Report a vulnerability** (비공개)
- Or email / 또는 이메일: pikiforyou@gmail.com

Please include / 포함해 주세요:
- Affected version and site (ChatGPT / Claude / Gemini) / 영향받는 버전과 사이트
- Steps to reproduce / 재현 방법
- Impact / 영향

We aim to acknowledge reports within 7 days.
접수 확인은 7일 이내를 목표로 합니다.

## Scope / 범위
- In scope: this extension's code (content.js, popup, manifest)
  범위 안: 이 확장 프로그램의 코드
- Out of scope: the AI websites themselves (ChatGPT, Claude, Gemini)
  범위 밖: AI 사이트 자체

This is a personal open-source project with **no bug bounty program**.
개인 오픈소스 프로젝트이며 **보상(바운티) 제도는 없습니다.**
